# 🦴 FractureScan AI - Bone Fracture Detection

FractureScan AI is a modern, web-based demo application that leverages Deep Learning to detect bone fractures from X-ray scans. Built with a Django backend and a sleek, responsive frontend, it allows users to upload X-ray images and receive instant AI-powered diagnostic predictions with confidence scores.

---

## ✨ Features

- **Drag & Drop Interface:** Modern, intuitive UI for easy image uploading.
- **Real-Time AI Inference:** Processes images through a custom-trained `InceptionResNetV2` model.
- **Dynamic Results:** Displays real-time classification (Fractured / Not Fractured) with animated probability bars and confidence scores.
- **Privacy-First:** No patient data or uploaded images are stored in a database; images are processed in memory and discarded.
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

- **Backend:** Django (Python)
- **Machine Learning:** TensorFlow / Keras (`InceptionResNetV2` architecture)
- **Image Processing:** Pillow (PIL), NumPy
- **Frontend:** HTML5, CSS3 (Custom UI), Vanilla JavaScript (Fetch API)
